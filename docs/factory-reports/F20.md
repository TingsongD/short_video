## Design decisions

- **Exact duration is a sample count.** `construct_bed` renders declared
  loops joined by linear crossfades, then trims/pads to `round(s×rate)`
  samples — the plan records `exact_samples` and `joins_inspected`, so a
  reviewer inspects each boundary instead of narration masking gaps.
- **Levels are measured, not assumed.** `pcm.measure` reports
  peak/RMS/clipped facts; the loudness "target" carries its
  `basis` ("fixture qualification") rather than claiming a platform
  spec. Over-loud input is repaired by a documented gain reduction
  recorded as `repaired_db`, not a silent cap.
- **Frozen profile per experiment.** `MixProfile` pins bed, gains,
  duck regions and channels under `profile_hash`. Variant copy changes
  go through the same profile; `region_parameters` +
  `assert_unchanged_identical` give executable evidence that music in
  unchanged regions is byte-for-byte equivalent and any ducking is
  confined to the declared interval.
- **Music auth is its own route.** `FakeMusicGen` carries an `authed`
  flag — `route_auth_required` proves Vertex video OAuth does not
  qualify the music route. Generation runs through `Executor` intent →
  `reconcile` recovery: a lost ack finds the remote op by id/hash and
  never resubmits; an imported bed touches no generation op at all.
- **Provenance split.** Imports record `source="imported"` +
  `license_ref`; generation records `source="generated"` + model ref.
  Beds used in delivered files are revised, never overwritten — a
  construction produces a new artifact (`bed:<id>:constructed`).

## Known limitations

- PCM layer is 16-bit mono-first (stereo by duplication); a mastering
  path (F23 render) may swap in ffmpeg loudnorm — profile hash pins the
  parameters either way.
- `seed_brief` is a descriptor pass-through until F12 audio analysis
  emits richer rhythm/arrangement fields.
- True-peak measurement is approximated by sample peak; documented as
  `peak_dbfs`, not claimed as ITU-R BS.1770.
- SFX remain separate timed assets — `mix(tracks=[...kind:'sfx'])`
  honors offset/gain but no dedicated SFX catalog record exists yet
  (deferred to F21 asset graph).
