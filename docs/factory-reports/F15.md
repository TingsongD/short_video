# F15 — Shared generation contract and provider routing

**Module / owner / source revision / completion date:** F15 · Devin · `feat/factory` post-F14 · 2026-09-17

**Scope implemented:** neutral `GenerationRequest` + adapter contract + dated capability evidence + deterministic routing with explanatory verdicts.

- `modules/factory/providers/base.py` — `GenerationAdapter` interface: `readiness`, `capabilities`, `validate` (side-effect-free), `price`, `prepare`, `submit`, `observe`, `download`, `reconcile`, optional `cancel` (`cancel_not_supported` by default). Validation covers aspect, resolution, per-kind reference counts and audio policy — before any pricing.
- `modules/factory/providers/catalog.py` — `CapabilitySnapshot` record keyed `cap-<provider>-<model>-<location>-<input_mode>`, immutable revisions, `support ∈ advertised|observed|qualified`, `valid_until`. `CapabilityCatalog.latest` returns snapshot + `stale` flag — a dated snapshot that's expired is reported, never silently trusted.
- `modules/factory/providers/router.py` — `ProviderRouter.route(request, policy, authorization, now)`: candidates from policy (`jimeng`/`vertex`/`jimeng_with_vertex_fallback` → `jimeng_canvas`/`google_vertex`). Per candidate: adapter presence, plan lock (`plan_locked_to`), model lock (`model_locked_to`), authorization scope (`not_in_scope`), readiness (`not_ready` — **disqualifying early return**; a provider that can't auth/quote is never model-evaluated), capability snapshot (`no_capability_snapshot`, `stale_capability_snapshot`, `unqualified_support` below `observed`), adapter validation, duration rounding UP to the smallest supported catalog choice (`duration_uncovered` → split/replan named), price, and cap check (`exceeds_cap:<unit>`). Returns the decision plus `rejected` map — every cheaper/faster alternative names why it wasn't eligible. `fallback_blocked_reason(attempt_id)` defers to the Executor: an unresolved original suppresses paid fallback (`original_unresolved`).
- `modules/factory/testing/fakes.py` — `FakeGenerationAdapter` (model catalog + price table over persistent `FakeProvider`) and `JIMENG_MODELS`/`VERTEX_MODELS` scripted capability sets (jimeng: 4/8 s, image refs only, no audio, credits; vertex: 4/6/8 s, image+video refs, audio, USD micros).
- Money stays independent: each route prices in its own unit — credits can never satisfy a USD request and vice versa.
