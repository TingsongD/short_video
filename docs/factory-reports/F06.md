# F06 — Dependency scheduler, capacities and leases

**Module / owner / source revision / completion date:** F06 · Devin · `feat/factory` post-F05 · 2026-09-16

**Scope implemented:** `Scheduler` over schema v5 (`capacities`, `capacity_holds`, `scheduler_flags`). DAG validation (`validate_dag`: cycles, unmet/self deps, duplicates) before `submit_plan` writes a row; transactional `claim(queue)` with worker ID + lease expiry + fencing token; every mutation (`complete`/`fail`/`transition`) verifies owner + fencing + expiry, `FencingError` otherwise; three claim classes — dispatch / observe / collect — so a slow submission never blocks collection; global capacity rows shared across workers and experiments (Jimeng 5, Vertex 1, local render 1, plus download/observe/dispatch pools); `pause`/`drain` flags stop only dispatch; `reclaim_expired` returns leased work to ready while *retaining* capacity holds for jobs with unfinished remote attempts; `ResourcePolicy` gates heavy local work on free disk; blocked descendants carry an ancestor reason.
