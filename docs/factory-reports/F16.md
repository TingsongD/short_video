# F16 — Official Jimeng Canvas adapter

**Module / owner / source revision / completion date:** F16 · Devin · `feat/factory` post-F15 · 2026-09-17

**Scope implemented:** `CanvasAdapter` — the official `dreamina-canvas` CLI wrapped behind the F15 `GenerationAdapter` contract, plus an argv-level `FakeCanvasRunner` with persistent JSON state for offline drills.

- `modules/factory/providers/canvas.py`
  - `readiness()` → `cli.doctor()`: version/commit, region, environment, verified `userId`; `expected_user` rejects a **wrong-account reconnect** (`account_mismatch`); expired login → `login_required`; malformed/timeout/missing CLI each named distinctly (`invalid_response`, `transport_timeout`, `cli_missing`, `unsupported_cli_schema`).
  - `prepare(request)` → canvas create + node create, **idempotent by request hash** — a restart reuses the same project/node IDs and never spawns duplicate paid nodes.
  - `prepare_quote(request)` → native `node quote` → `maxCredits` ceiling + per-node items + `draftVersion`.
  - `submit(request)` → `node confirm` (credit-ceiling) → `node run` with the confirmation token inside the CLI call frame only; the token is never stored or logged. `submit_id` derives from the request hash so a repeated submit maps to the same remote identity.
  - `observe` / `download` / `reconcile` / `cancel` — poll by saved IDs through `node show`; download via `resource download` with sha256; `reconcile` finds remote work by operation ID or `sub-<request_hash>` submit-id **even when the local op map was lost** (adopts the remote record, then observes). `download` failure is a transient transfer error — it never regenerates.
- `modules/factory/testing/fakes.py` → `FakeCanvasRunner`: argv dispatcher returning `CompletedProcess`-shaped JSON envelopes (`schemaVersion:1`); persistent canvases/nodes/ops/auth state; drills: `expire_login`, `reconnect(user_id)`, `set_fault` (`cli_missing`, `transport_timeout`, `malformed_json`, `credit_reject`, `partial_quote`, `download_fails`, `node_fails`), `lose_next_run` (accept remotely, drop the response).
- Legacy reuse honored: all transport goes through `modules/assets/canvas_cli.py` unchanged — bounded timeouts, no argv/stdout/stderr in errors, token hygiene preserved by construction.
