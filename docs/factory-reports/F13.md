# F13 — Reusable format and template authoring

**Module / owner / source revision / completion date:** F13 · Devin · `feat/factory` post-F12 · 2026-09-17

**Scope implemented:** accepted blueprint → versioned `FormatTemplate` with timed slots, constraints, declarative effects and a renderer capability manifest — reusable structure only, no source content.

- `modules/factory/templates/authoring.py` — `author_from_blueprint(bp, id)`: requires `status=="accepted"` (`blueprint_not_accepted` otherwise). Maps beat roles → slot kinds (`hook|product|proof|cta|transition`), derives `frames` from the beat's target interval and `min_frames`/`max_frames` at 0.5×/1.5×. Product/proof slots require an `image` reference. Constraints: caption region/safe zone/max chars, music bed + duck-under-speech, transition defaults. `derived_from_blueprint` keeps provenance — slots carry `beat_role` only, so transcript text, product names and presenter identity never ride into the template. `DEFAULT_CONSTRAINTS` is deep-copied per template (a shallow copy leaked caption edits between templates — caught by test).
- `modules/factory/templates/capabilities.py` — `RENDERERS` manifest: `ffmpeg_fast` (cut/crossfade/static_image/text_overlay/audio_bed) and `hypit` (+ animated_overlay/motion_track/lip_sync). `capability_report(slots)` routes each slot to the cheapest renderer covering its effect+transition set; unknown effects → `unsupported` named in the report, never dropped. `preferred` is ffmpeg_fast only when *every* slot fits it.
- `modules/factory/templates/validate.py` — `validate_template`: slot bounds (`min>0`, `max>=min`, `frames>=min` → `under_min`), total coverage via `check_partition` against the plan's frame clock, `missing_handles` for crossfade without `handle_frames`, `missing_reference` against supplied ref counts, `missing_font` against the font manifest, `unsupported_effect` named, and `source_leakage` when seed text appears in slot content. `to_legacy_format` exports to the frozen `format_library` shape only when nothing richer than prose beats would be lost — otherwise `legacy_export_lossy`.
- `modules/factory/templates/service.py` — `TemplateService`: `author` (validate+persist+event), `revise(mutate, reason)` → new revision row (old stays readable — pinned plans keep their appearance), `set_status` (candidate/proven/retired only; promotion evidence belongs to F33), `plans_bound_to` for compat checks, `preview` → machine spec + human-readable slot map.
- `modules/factory/domain/records.py` — `Slot` gained `frames`, `effects`, `transition_out`, `handle_frames`, `content` (defaults keep prior bodies loadable).
