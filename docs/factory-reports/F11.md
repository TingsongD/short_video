# F11 — Shopify product and media snapshots

**Module / owner / source revision / completion date:** F11 · Devin · `feat/factory` post-F10 · 2026-09-17

**Scope implemented:** authorized read-only Shopify Admin GraphQL import → immutable `ProductSnapshot` revisions with variant/media coverage, verified reference artifacts and factual claims only.

- `modules/factory/integrations/shopify.py` — adapter over an injectable `transport(query, variables)` that carries auth outside the adapter. `MUTATION_RE` refuses any query containing `mutation` **before** dispatch (`writes_forbidden`); API version pinned `2026-04` (verified with the pilot store per `docs/shopify-product-assets.md`). `LiveShopifyAdmin` implements the real read queries: paginated `products`, nested `media` connections, `productByHandle`, `node(id:)` refresh for expiring media URLs. GraphQL `ACCESS_DENIED` → `missing_scope`; HTTP 401/403 → `missing_scope`; non-2xx → typed `shopify_http_error`. CDN downloads go through the F09 SSRF guard (`assert_fetchable`) before fetch.
- `modules/factory/products/importer.py` — `ProductImporter.import_catalog` walks every product page (`inventory_complete` only when `hasNextPage` observed false) and per-product nested media pagination before claiming completeness. `snapshot_product` downloads each media URL through `media_download`; `expired_source` triggers the adapter's refresh path once, then F04 `intake_bytes` (probe-validated kind, SHA-256 dedupe, `shopify` provenance + source key). Snapshots are immutable revisions keyed `psnap-<sha(shop|product)>`: revision identity is a hash over the **facts** (clock fields `observed_at`/`created_at`/`revision`/`content_hash` excluded), so an identical refresh writes nothing while a real price/availability change writes `revision+1` — prior revisions stay readable, keeping a running experiment bound to what it was approved under.
- Claims are factual only: title, sanitized `description_text` (HTML→text via a small parser; the source HTML is retained in the raw catalog row, not in the claim), variant, price (typed `Money usd_micros` via `Decimal`), availability. `selection_basis` is always `manual_selection` with `popularity_evidence: null` — no "best seller" is ever invented.
- `select` dedupes by `product_id`, flags `duplicate_product:` and `unavailable_variant:` warnings. `reference_gap` returns `covered: false / insufficient_views` for a single image, `covered: true` for video, `covered: null` when multiple images still need human angle review — a snapshot never claims unshown angles.
- `storefront_product_ref` resolves `/products/<handle>?variant=<id>` URLs to exact IDs; `resolve_storefront` snapshots by handle+variant.
- `modules/factory/testing/fakes.py` — `FakeShopify`: persistent scripted catalog (the `shopify-catalog` fixture shape), local-dir media bytes, `expires` flag → `expired_source` until `refresh_media_url`, `remove_permission` → `missing_scope` on download. Survives restarts like every other fake.
- `modules/factory/domain/records.py` — `ProductSnapshot` gained `pagination_complete`, `media_coverage`, `warnings`, `revision`, `content_hash`.

**Read-only guarantee:** mutations are refused in `graphql()` before transport is invoked; the only "write" surface is Shopify's own URL-refresh read. No Shopify mutation exists anywhere in the adapter.
