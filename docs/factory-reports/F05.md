# F05 — Prices, budgets, approvals and reservations

**Module / owner / source revision / completion date:** F05 · Devin · `feat/factory` post-F04 · 2026-09-16

**Scope implemented:** `BudgetService` over schema v4 (`budgets`, `reservations`, `reservation_lines`, `ledger_imports`). Independent units (Jimeng credits / other native credits / USD micros — never interchangeable); multi-line atomic reservations (provider sublimit + aggregate checked and held in one transaction); held **and** ambiguous reservations count against caps; same `request_hash` replays the same reservation (idempotent); evidence-only `release()`; idempotent `settle()` with four distinct kinds (`native_quote`, `usage_estimate`, `reported_usage`, `invoice_confirmed`); over-reserved settlement refused unless correction headroom exists; `check_authorization` preflight binding plan hash, provider/model allow-lists, unit caps, quote freshness and provisional flags; `spend_breakdown` read-only view; idempotent legacy `ledger.json` import that preserves history and creates no new authority.
