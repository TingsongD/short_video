## Design decisions

- **Owned before it runs.** `register` persists build id, workspace,
  composition hash and renderer before any process starts — the same
  intent-before-effect discipline as provider submits.
- **Sections are the resumable unit.** Each picture input normalizes
  to a cache file keyed `sha(source)-frames@fps` with a sha receipt.
  Verified caches resume an interrupted render with **zero
  re-encodes** (test: 8 sections, observer killed at concat, resume
  normalized nothing). `progress.json` stamps `current` +
  `completed_sections` with timestamps for post-crash context.
- **Coverage is verified, never padded.** `normalize_section`
  post-probes `nb_frames`; a 9-frame source allocated 30 frames fails
  `short_footage` instead of freezing. A 24 fps native clip becomes
  exactly 30 fps/30 frames — no drift.
- **Observer ≠ build.** A `subprocess.TimeoutExpired` on the local
  encode or a `status` timeout maps to `observer_lost`/`unknown` —
  never `failed`. The hypit path keeps its `remote_build_id` and
  resumes observation of the SAME build; nothing submits twice.
- **The returned file is the deliverable.** `collect` retrieves via
  `get --output` (hypit) or the workspace final (fast path), verifies
  recorded `output_sha256`, refuses `output_mismatch`, and registers
  through `intake_bytes` — never assumes a path inside the production
  dir.
- **Renderer choice is recorded.** `RenderBuild.renderer` +
  `renderer_version` field; static parity qualification before
  switching a template's renderer is F24/QC's call.

## Known limitations

- Section cache covers normalized inputs; the final concat encode
  always reruns (deterministic tail — cheap, bounded).
- Audio path supports per-source gain + amix/alimiter; the F20 mix
  profile integration (duck regions, loudness target) is F24 QC's
  verification surface.
- Hypit build observation was faked in tests; a live `hypit build`
  run belongs to a funded/local-runtime session, not the unit suite.
- `RenderService.dispatch` runs synchronously; F06's `local_render`
  capacity serialization wraps it when the worker lands (F26).
