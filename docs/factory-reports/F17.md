# F17 — Google Vertex video adapter

**Module / owner / source revision / completion date:** F17 · Devin · `feat/factory` post-F16 · 2026-09-17

**Scope implemented:** `VertexAdapter` for the asynchronous Interactions API on the recorded pilot route (`gemini-omni-1.1-flash-preview`, `global`), plus the `VertexAuth` OAuth boundary and persistent fakes.

- `modules/factory/providers/vertex_auth.py` — `VertexAuth(loader, project, location, required_scopes)`: injected `loader()` supplies credentials; `status()` distinguishes `api_key_only` (rejected for this route — `GEMINI_TTS_VERTEX_API_KEY` proved 401), `expired`, `wrong_project`, `missing_permission`, `quota_exceeded`, `no_credentials`, `loader_failed`. The access token never appears in status output or `__repr__`; `refresh()` re-runs the loader after user reauthentication.
- `modules/factory/providers/vertex.py` — `VertexAdapter`:
  - **Exact pilot payload**: `model`, `background: true`, `input[]`, `response{format,aspect_ratio,resolution,duration:"Ns"}`, `generation_config.video_config.task` mapped per input mode (`text_to_video`/`reference_to_video`/`video_to_video`), `audio` flag explicit from `native_audio_policy`. `delivery`/`gcs_uri` are never emitted — the pilot's `delivery:"uri"` without a bucket is a confirmed terminal `invalid_request`.
  - **HTTP 200 ≠ success**: `submit` treats 200+ID as acceptance; terminal `errors[]` on the POST response raise named faults; `observe` maps `status` and surfaces `errors` — a 200'd GET can still be a failed interaction.
  - **Usage honesty**: `observe` returns `reported_usage` (labeled `reported_estimate`) or `None` when absent — never zero.
  - **Validated inline decode**: base64 validated, empty/oversize rejected (`malformed_media`, `media_size_out_of_bounds`), sha256 returned; `delivery_requires_gcs` raised if a URI output appears without a configured bucket.
  - `price`/`estimate`: dated rate snapshot → `usd_micros` estimate (`kind: estimate`, `rates_dated`) — 4 s reproduces the pilot's $0.409384.
  - `reconcile` by interaction ID or request hash; `cancel` via `:cancel` mapped to `cancel_not_supported` when the route refuses.
- `modules/factory/testing/fakes.py` — `FakeOAuthLoader` (persistent credential doc; `expire`/`reauth`/`api_key_only`/`switch_project`/`revoke_scope`/`set_quota` drills) and `FakeVertexTransport` (persistent interactions; 401 for API-key/expired, 404 wrong-project, 429 quota, `delivery:uri` → accepted-then-terminal, `lost_posts` leaves a real remote interaction, `http200_terminal`, `missing_output`, `malformed_b64`, `download_fails` = transient media-retrieval failure that leaves the op SUCCEEDED).
