# F19 — TTS, speech fitting and alignment

**Module / owner / source revision / completion date:** F19 · Devin · `feat/factory` post-F18 · 2026-09-17

**Scope implemented:** normalization, identity-bound segments, TTS dispatch through F07 intents, waveform measurement, injected alignment, documented fit limits, transform-aware captions, and cross-variant cache reuse.

- `modules/factory/domain/records.py` — `SpeechSegment` (voice/model/language/settings + `normalization` + normalized `text` → `cache_key`; measured `duration_s` stays `None` while unknown; `speech_hash` pins the approved version for lip-sync), `WordAlignment` (word timings validated monotonic, bound to `audio_sha256` + `spoken_text`), `CaptionSet` (cues mapped through the fit transform, bound to `speech_hash`).
- `modules/factory/audio/speech.py` — `SpeechService`:
  - `normalize` reuses `modules/script/voicetext.clean` (numbers→words, contractions expanded, markup stripped) then **rejects surviving markup** (`markup_in_speech`) and empty results — markup is never spoken.
  - `cache_key` = hash of voice_id+model+language+settings+normalization+text — the exact identity two variants must share to reuse audio; a changed hook is a different key, not a reread.
  - `synthesize` → F05 reservation (idempotent by request hash) → F07 `prepare`/`submit` (`tts_synthesis`); lost ack → attempt `unknown`, remote op preserved.
  - `collect` → observe→download→F04 intake→measured duration from the probed waveform; `recover` reconciles by request hash (`no_remote_trace` is the only state permitting a new attempt).
  - `reuse_from_cache` — a planned segment adopts an identical earlier segment's artifact/duration/status: same bytes, zero new synthesis.
  - `approve` pins `speech_hash` (mismatch → `revision_mismatch`; unfitted → `not_fitted`).
- `modules/factory/audio/fit.py` — `fit_plan(duration, target, trim)`: documented limits `TRIM_MAX_S=0.9/edge`, `PAD_MAX_S=2.0`, `RATE ∈ [0.90,1.10]`; outcomes: fits (pad/rate documented) or named failure (`speech_too_long`, `pad_exceeds_limit`, `trim_exceeds_limit`) with a copy-revision action — **words are never truncated**. `apply_fit` maps word timings through trim+rate.
- `modules/factory/audio/alignment.py` — `AlignmentService`: injected aligner (own budget/retry at the caller level) produces `WordAlignment` bound to the exact waveform hash; `captions` maps aligned words through the fit into frame cues.
- `modules/factory/testing/fakes.py` — `FakeTTS` (persistent ops; WAV is real probeable PCM synthesized deterministically from word count; usage=characters estimate in `elevenlabs_credits`; `lost_submits`/`synth_fails`/`download_fails`/`quota` drills; reconcile by request hash) and `FakeAligner` (deterministic evenly-spaced timings, edge silence excluded).

**Known risks / deferred:** `FakeAligner` timings are synthetic — real alignment service integration carries its own budget/retry and is deferred to a later qualification. Rate adjustment above ±10% is deliberately impossible here; copy revision is the intended escape. Native credit *settlement* for TTS awaits real usage reports (usage stays a labeled estimate).
