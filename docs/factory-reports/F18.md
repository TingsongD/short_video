# F18 — Product, presenter and outfit references

**Module / owner / source revision / completion date:** F18 · Devin · `feat/factory` post-F17 · 2026-09-17

**Scope implemented:** reference packs bound to product/variant + presenter with source provenance, per-attribute validation, hash-pinned acceptance, bounded repair, dependent-work invalidation, and an authorized Canvas image-generation path.

- `modules/factory/domain/records.py` — three new records:
  - `PresenterIdentity` — `fictional|licensed` kind, continuity guide (appearance/setting/framing/wardrobe), required `provenance`; `seed_frame` provenance is a typed rejection (`seed_presenter_copied`) — the seed's presenter can never be embedded.
  - `VisualReference` — role ∈ product_front/back/detail, presenter_headshot/full, style, scene; origin ∈ manual_import|product_snapshot|generated; `artifact_sha256` pinned; `acceptance.reviewed_hash` must equal the artifact's sha or the record fails validation; typed attribute states `observed|inferred|unknown`.
  - `ReferencePack` — product/variant/presenter binding + `required_roles`, `pack_hash` (sha of `{role: artifact_sha256}` for accepted refs — the identity A/B/C/D share while locked variables hold), `repair_attempts`, `plan_hash`.
- `modules/factory/references/pack.py` — `ReferencePackService`: `create_presenter`, `create_pack`, `from_snapshot` (F11 media → product_snapshot refs, images only, front/detail roles), `add_reference` (manual import parity — real artifact, image kind only), `selection`, `refresh_pack_hash` (ready ⇔ all required roles accepted), `replace` (new revision, `parent_hash`, old superseded — never a mutation), `dependents` (generation requests + reviews bound to **any** artifact hash ever attached to the pack — all revisions scanned, so a replaced hash still lists its consumers), `invalidate` (pack → stale, bound reviews get `invalidated_by`, event recorded; nothing silently migrates).
- `modules/factory/references/validate.py` — `validate_reference(ref, snapshot_facts)`: per-attribute verdicts `match|mismatch|unknown_view`; flags `missing_view` (attr unevidenced — stays uncertainty), `inferred_attribute`, `attribute_mismatch`, `invented_detail` (construction/detail with no source claim), `copied_source_overlay`, `seed_presenter_copied`.
- `modules/factory/references/review.py` — `ReferenceReview`: `accept` gated on exact `artifact_sha256` (`revision_mismatch` on drift) **and** zero unresolved flags; `reject` requires reasons; `replace` bounded by `max_repairs` (attempts counted on the pack); `gate_request` — rejected/pending hashes raise `reference_not_accepted` before any paid picture job.
- `modules/factory/references/generate.py` — `ReferenceGeneration`: F05 reservation (`budget.reserve` idempotent on request hash) → F07 `prepare`/`submit` (`reference_generation` kind, attempt id persists) → `collect` (observe→download→F04 intake→pending ref) → `recover` (reconcile by request hash; `no_remote_trace` is the only state permitting a new attempt).
- `modules/factory/providers/canvas.py` — `prepare` honors `request["kind"]="image"` → `node create image`/`t2i` (duration only for video).
- `modules/factory/testing/fakes.py` — `FakeCanvasRunner` image downloads return a real probeable PNG (`bytes_b64`); `resource download` schema flag added; `projectId` stored on ops for remote reconcile.

Style/scene roles exist but aren't exercised by QA cases yet. Vertex image generation remains unimplemented and unqualified, per spec.
