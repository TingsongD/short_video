# F12 — Reference analysis and blueprint review

**Module / owner / source revision / completion date:** F12 · Devin · `feat/factory` post-F11 · 2026-09-17

**Scope implemented:** verified source media → probed clocks + local evidence → bounded analyzer call → timed `ReferenceBlueprint` draft → hash-gated review with accept/reject/edit.

- `modules/factory/media/scenes.py` — ffmpeg `select=gt(scene,…)` + `showinfo` parse → timestamped candidate cuts with scores (bounded 120 s; a static source honestly returns zero candidates).
- `modules/factory/media/audio.py` — stream presence + `volumedetect` levels. Missing stream → `present:false`; loudness never proves speech — `speech:"unknown"` until a transcript confirms it.
- `modules/factory/media/frames.py` — `-ss` frame extraction to PNG; the source is never written to.
- `modules/factory/analysis/analyzer.py` — `parse_analysis`: strict shape check (roles, confidence enum, word timings inside segment bounds, end>start) → `malformed_analysis` ContractError, not a partial blueprint.
- `modules/factory/analysis/service.py` — `AnalysisService.analyze(seed_id)`: requires `media_ready` + a probed **video** artifact (image-as-source → `source_not_video`). Probes clocks; gathers scenes/audio locally; dispatches the multimodal call through the F07 `Executor` (intent+attempt+outbox before dispatch; request carries artifact sha, duration, scene candidates, audio presence, input mode). Beats get `source` FrameIntervals on the source clock AND `target` FrameIntervals on the output clock — each mapped once via `seconds_to_frames`, last beat snapped to `target_frames` so `check_partition` tiles exactly. One representative frame per beat is extracted at the midpoint and intaken with `derived:analysis` provenance → `evidence_ids`. Speech keeps `observed_source_text: true` + pace (words/s); `adaptation` declares `requires_new_copy` + `new_selected` voice + `fictional_or_authorized` presenter. `resume(attempt_id)` finishes a prepared/reconciled attempt without resubmitting — one remote op survives a lost ack.
- `modules/factory/analysis/review.py` — `BlueprintReview.flags`: partition gaps/overlaps, `untranscribed_speech`, `audio_missing`, `low_confidence_scene`, `unclear_product_action`. `accept` requires zero flags AND the exact `content_hash` the reviewer saw (`revision_mismatch` otherwise). `edit(mutate, reason)` writes a child draft revision with `parent_hash`, marks the old row `superseded`, and returns `stale_dependents` (templates/experiments bound to the old hash) — dependents are surfaced, never auto-migrated.
- `modules/factory/testing/fakes.py` — `FakeAnalyzer`: FakeProvider lifecycle with per-sha scripted analysis payloads (or a duration-fitted 3-beat default); `malformed-analysis` fault; request retained on the op even when the ack is lost, so reconcile-by-hash works.

**Deviations from the module guide:** analysis runs through the generic Executor rather than a dedicated scheduler job — the F07 protocol already provides the durable worker boundary (persisted intent, reconcile, bounded retries); scheduler wrapping can layer on in F21 when plans dispatch real work.

**Known risks / deferred:** the scripted analyzer is honest about input mode (`video+audio`) but a real multimodal provider's supported input modes/cost bounds are unverified — live qualification under F35. Scene detection on synthetic color sources returns zero candidates (correct); real-content thresholds may need tuning. Word-level alignment is validated structurally only.
