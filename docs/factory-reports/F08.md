# F08 — Events, timing and observability

**Module / owner / source revision / completion date:** F08 · Devin · `feat/factory` post-F07 · 2026-09-17

**Scope implemented:** durable event spine + derived observability. Events are monotonically `seq`-numbered inside the same transaction as the state change (F03 outbox/events infrastructure), so a crash can never produce a state with no causal event. `EventSubscription` provides cursor-based `replay`/`replay_all`, `snapshot` resync (returns the durable projection — job/attempt/record — plus the event high-water mark), and `retain` which trims old events *and writes a `retention_marker` row* so gaps are explainable. A cursor below the retained window raises `ResyncRequired` naming the earliest retained seq and the snapshot route — never silent skipping; duplicate delivery is naturally tolerated since replay is seq-ordered and idempotent on the consumer side. `timeline()` derives per-stage durations — queue wait (planned/prepared/ready → claimed), dispatch, provider elapsed (preferring the provider-reported `provider_finished_at` inside the event body, with an explicit uncertainty note when only poll-observed time exists), collection delay, review, render, wall-clock, turnaround — `None` where evidence is absent, never zero. `redact()` strips Google API keys, OAuth tokens, Bearer strings, access/refresh token fields, confirmation codes, and signed-URL params (`sig`, `X-Goog-Signature`, `Expires`, …) recursively from payloads; artifact/receipt references survive. `health_report()` emits actionable signals — `stale_lease`, `unknown_attempt`, `prolonged_ready`, `storage_pressure`, `undelivered_intents`, `unresolved_approvals` — each naming owner, state, and next action, all evaluated as-of a passed `now` (deterministic under FakeClock tests).
