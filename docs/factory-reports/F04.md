# F04 — Artifact registry, media intake and provenance

**Module / owner / source revision / completion date:** F04 · Devin · `feat/factory` post-F03 · 2026-09-16

**Scope implemented:** `ArtifactStore` with owned `staging/`, streaming SHA-256 during copy, bounded-timeout ffprobe classification (streams are truth; extension is a hint), atomic `os.replace` promotion into content-addressed `blobs/`, per-import source attributions in `artifact_sources` (identical bytes → one blob, both attributions kept), `derived/` versions with transformation metadata retaining native facts, actionable rejection codes (`zero_bytes`, `unprobeable`, `no_streams`, `kind_mismatch`, `resolution_too_small`, `duration_too_short`), empty-folder → missing-list (no exception), `recover_staging()` distinguishing `unreferenced_temporary` from `referenced_missing`, and ID-only serving with realpath containment (traversal + symlink escapes refused). Schema v3 adds `artifact_sources` + `artifact_links` (reference counts for later retention).
