## Design decisions

- **Bindings are explicit, never folder order.** Every segment binds
  `{binding, role, artifact_id, sha256, in_frame, out_frame, track}` in
  `manifest.json`; the SVML references `./assets/<seg>.<ext>` and the
  compiler materializes artifact bytes into the composition dir — the
  pinned runtime's `check` resolves them (`Source is valid, 15
  outputs` on the canonical compile).
- **Deterministic = same bytes, same revision.** Identical inputs
  recompile to identical file hashes → `reused_revision`; a changed
  selection produces revision N+1 with `parent_hash` and exactly the
  changed bindings differing (M04: only `src-s2` changed).
- **Failed compiles don't consume revisions.** Diagnostics persist a
  `failed` record for audit; `_latest` numbers only successful
  revisions.
- **Diagnostics are located.** `missing_asset@segment[s2]`,
  `stale_selection` (bound sha ≠ artifact sha), `insufficient_duration`
  (needs 6 s of 4 s), `unsupported_effect` per renderer manifest,
  `overlap`, `bad_interval` — compile errors emit no files and never
  touch providers.
- **Captions use the proven escape helper.** `escape_markup_text`
  emits `&apos;`/`&quot;` named entities (Hypit 0.1.8 does not decode
  `&#x27;`); a roundtrip decode test proves visible text matches
  intent, Unicode passes through.
- **The plan gate audits the real schema.** `hypit plan --json`
  returns `needs[].capability` (e.g.
  `@hypit/media-pipeline@1#normalize-media`); the audit allowlists
  local `@hypit/` prefixes and fails any other namespace as
  `hosted_step`. Verified against the actual pinned runtime — canonical
  plan's 5 needs all audited clean.
- **Renderer capabilities are declared.** `RENDERER_EFFECTS` separates
  `hypit` (kenburns, inset, …) from `ffmpeg_fast` (cut/crossfade/
  caption); an unsupported effect is a located diagnostic, not silent
  drop.

## Known limitations

- SVML emit covers the proven local vocabulary (timeline, normalize,
  media/typo tracks, film, render target). Richer components
  (insets, MG) extend the allowlist as templates need them.
- `style.svs` is a fixed sheet; template-driven styling lands with F23
  renderer qualification.
- Composition `check`/`plan` verified against the real pinned runtime;
  `build` remains F23's job and is never invoked here.
- M02's pixel-level caption proof requires a real render — deferred to
  F23-M01 by design.
