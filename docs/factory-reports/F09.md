# F09 — Seed registry and source acquisition

**Module / owner / source revision / completion date:** F09 · Devin · `feat/factory` post-F08 · 2026-09-17

**Scope implemented:** URL intake → canonical Seed → observed metadata → verified source artifact. `parse_source_url` auto-detects youtube/tiktok/instagram hosts and canonicalizes via the existing `video_reference` rules (tracking params dropped, distinct posts never conflated); the original URL form and acquisition `via` are kept as provenance observations on the Seed record. `SeedRegistry` dedupes on a deterministic id (`seed-<platform>-<sha256(native_id)[:16]>` — ID_RE-safe for case-sensitive native ids), stores each mutation as a new immutable revision (provenance append-only, history never lost), and derives `readiness()` — `metadata_only`/`needs_source_media` explicitly fail `analysis_ready` with named next actions. `AcquisitionService` plans two scheduled jobs per seed (`seed_metadata:` → `seed_media:` logical keys, real F06 leases/capacity) and runs them through the F07 executor (intent+attempt persisted before any remote call, remote id on ack, resume-by-attempt on transient cuts — an interrupted download retries the SAME attempt's transfer, never resubmits). Metadata TTL caching avoids repeat paid lookups (`cache_hit` event, no second submit). F05 reservations wrap priced calls when `costs` configured (reserve → `native_quote` settle / release on pre-acceptance failure). SSRF guard `assert_fetchable` refuses non-https, credentialed, non-443, and any host resolving to non-public IPs (injectable resolver keeps tests offline); `ViralOutliersSource` follows redirects manually with per-hop revalidation (max 3) and bounds payload bytes; expired media URLs go through `refresh_url` — the approved path — then one pre-acceptance resubmit. `attach_media` requires a probe-verified `video` artifact and satisfies the seed's media job + unblocks/promotes analysis dependents; `import_manual` does the same for local uploads, so a manual video resumes blocked analysis with zero paid calls. Stats land as `MetricObservation` records (unknown counts stay null+reason). `submit_plan` now validates new nodes against already-persisted jobs so later phases can attach deps across plan boundaries.
