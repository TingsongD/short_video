# F03 — SQLite store and migrations

**Module / owner / source revision / completion date:** F03 · Devin · `feat/factory` post-F02 · 2026-09-16

**Scope implemented:** WAL database at schema v2 with `records` (revisioned domain entities, unique `(kind,id,revision)` + unique content hash), `jobs` (unique `logical_key`, ready-job index), `attempts` (unique `(job_id,attempt_seq)`, remote-id + unfinished indexes), `events` (stream-ordered cursor), `outbox` (transactional intents), `intents` (unique `(request_hash,kind)` dedupe), `artifacts`. `UnitOfWork` shares one `BEGIN IMMEDIATE` transaction across all repos; optimistic concurrency via `version` + `StaleRevisionError`; ordered migrations with `meta.schema_version`; `NewerDatabaseError` on forward-incompatible open; read-only `mode=ro` inspection; `sqlite3.backup`-based live backup/restore with `integrity_check` verification.

- `tests/test_factory_store.py` — 15 tests
