## Design decisions

- **Findings carry locations.** `black_section@1.0-2.0s`,
  `frozen_section`, `wrong_frame_count` (nb_frames vs expected —
  container padding is not picture duration), `decode_error` with the
  log tail, `silent_audio`/`clipping` from measured mean/max volume.
- **Two region-compare modes.** Normalized intermediates compare by
  sha — a difference is proof. Separately encoded finals compare by
  per-region SSIM with a calibrated 0.98 threshold, because codec
  noise is not a change. Audio regions compare sample-exact — a gain
  change outside the declared interval is a named leak with the first
  differing sample's timestamp.
- **Acceptance is hash-bound.** Every `Review` pins `target_hash`;
  `accept()` fails on `stale_review` when the file's current bytes
  differ. `invalidate_stale` marks reviews `invalidated_by` the new
  hash — old verdicts remain visible but can never accept new bytes.
- **Repairs are bounded.** `request_repair` counts per plan against
  `max_repairs`; the second request raises `repair_budget_exceeded`.
  A failed QC can never fan out to unlimited regeneration.
- **Evidence is extracted, not asserted.** `ReviewPack` pulls real
  frames via `select='eq(n,F)'` (exact index — `-ss` at the eof
  boundary silently yields nothing), covering first/last frame of
  every segment, product/detail checks, transitions and caption joins.
  Technical and creative verdicts stay separate records.

## Known limitations

- SSIM sampling is one frame per unchanged region (middle frame);
  denser sampling or full-region compare is a flag away if a leak ever
  slips through a single sample.
- `caption_text` evidence carries the literal string so entity defects
  can't hide behind a score; OCR-level caption-vs-pixels proof remains
  a manual-review step (F24-M01/M02 human checks).
- `compare_finals` runs one ffmpeg call per region — fine at experiment
  scale; batch extraction can optimize later.
- Creative review records are human/`agent` verdicts; no broad-model
  scoring is wired (by design it couldn't override specific checks).
