## Design decisions

- **Policy before publication is enforced.** `freeze_policy` scans
  publications through their variant plans and refuses to bind once
  the experiment has a public/scheduled post —
  `policy_after_publication`. `decide` refuses entirely without a
  policy — `policy_not_frozen`.
- **Reproducibility is structural.** `inputs_hash` covers the policy
  content hash, horizon, and every variant's snapshot id + coverage +
  metric values. Identical inputs return the existing decision with
  `_idempotent`; changed inputs mint a `-vN` decision and mark the
  previous one `superseded_by` — lineage never rewritten.
- **Every degenerate case has a defined outcome.**
  `waiting_for_data` (any incomplete coverage),
  `insufficient_exposure` (total below `min_exposure`),
  `inconclusive` + `zero_baseline` (control metric 0/missing — never
  infinite lift), `no_improvement` (all treatments lose),
  `inconclusive` (guardrail failure or `comparison_rule=all` unmet),
  `provisional_winner` (best lift ≥ `practical_lift`, guardrails ok).
- **Four posts = one experiment.** `independent_experiments` collects
  distinct `seed_id`s from winning experiments on a template;
  `promote` returns `unproven|promising|proven` with the sibling-
  variants limitation attached — a format cannot be proven by its
  own A/B/C/D.
- **Summaries cannot claim causality.** Every decision carries
  `observational`, `sibling-variants` and `multiple-comparisons`
  limitations; `summary` renders them, and tests assert no causal
  vocabulary appears.
- **Operator overrides are attributed.** `override_hypothesis`
  records the operator + note and emits an event — generation
  defaults are never silently changed by a noisy winner.

## Gate self-check (F33 spec)

- Frozen policy (metric/horizon/exposure/lift/guardrails/comparison
  treatment) before publication — **pass**.
- Complete comparable coverage required before ranking; A=0 → defined
  inconclusive; insufficient exposure → defined — **pass**.
- Observational labelling, no causal claims — **pass**.
- Immutable reproducible decisions referencing snapshots + policy +
  inputs; idempotent recompute; revised decisions on new data —
  **pass**.
- Promising treatment vs proven format separated; independent-seed
  counting explicit — **pass**.
- Searchable hypotheses with evidence/uncertainty; attributed
  overrides; no silent default changes — **pass**.

## Open risks / manual verification

- `provisional_winner` is deliberately named provisional — F35's
  release labeling must not treat it as proven without the
  independent-experiment count.
- Comparisons pool exposure across a publication's whole snapshot;
  very different posting times/accounts remain an observational
  caveat the dashboard should surface, not just the limitation text.
- `promote` currently looks up `ExperimentRevision` by the
  `<eid>-r<rev>` id convention — services that mint revision ids
  differently should go through `independent_experiments` with an
  explicit seed list.
