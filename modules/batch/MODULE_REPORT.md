# Sequential haul controller report

## Built

- `python -m modules.batch`: status, run/resume, live balance evidence, artifact
  review, explicitly quoted visual repairs, local picture fitting and zero-spend
  delivery dry run.
- `state.py`: private atomic checkpoints, single-controller lock, immutable
  selection check, full-video reservations and separate Jimeng/TTS limits.
- `canvas.py`: official native CLI discovery, reference imports/borrowing,
  draft readback, complete quotes, exact native ceilings, stable submission IDs,
  read-only recovery and verified downloads.
- `audio.py`: ElevenLabs v3 narration with durable request reservations, local
  pause removal, measured shot allocation and identically transformed captions.
- `picture.py` / `render.py`: bounded local speech-timing correction, source/audio
  hash checks, Hypit section builds, changed-input detection and continuous final
  audio assembly with FFmpeg. Original generated sources remain intact.
- `local.py`: owned process tracking, resource checks, verified Drive delivery,
  ambiguous-upload reconciliation and cleanup before advancement.

Operational procedure: `docs/msdressly-batch-runner.md`. The current-task
heartbeat supplies actual agent review and original copy authoring between
controller checkpoints; the shell controller alone does not perform those tasks.

## Contracts and remaining risks

No frozen schema or fixture changes requested or made. Recovery metadata is
separate local batch state. Native reference/quote limitations require provisional
ready references for preflight quotations; intended references are substituted
and re-quoted before generation within the accepted ceiling.

ASR timing is approximate and cannot prove visual lip synchronization. Actual
final viewing and caption checks remain required. Unknown requests must not be
resubmitted automatically. Credit snapshots must be refreshed between videos;
successful isolated examples do not guarantee that all selected videos fit the
remaining account balance or pass visual QC.
